    My analytics process

    The same five steps run through every project, from raw data to a recommendation.

    1. 01

      Collect

      Understand the business question and gather the right data sources.

    2. 02

      Clean

      Fix duplicates, missing values and formats so the numbers can be trusted.

    3. 03

      Analyse

      Query, model and test patterns in SQL, Excel and Python.

    4. 04

      Visualise

      Build dashboards in Power BI and Tableau that answer the question at a glance.

    5. 05

      Recommend

      Turn findings into clear actions a manager can take.

    AI in my workflow

    I use AI as a working tool at every step, and I check its output against the data.

    Clean

    Faster data preparation

    AI helps me spot missing values, duplicates and format issues, then write the Pandas or Power Query steps to fix them.

    Query

    SQL and DAX drafting

    I draft queries and measures with AI, then test them against known totals before they go into a report.

    Model

    Anomaly detection and forecasting

    Python models flag unusual transactions, classify fraud risk and project trends.

    Automate

    Repeatable pipelines

    Scripts ingest, clean, load to PostgreSQL and export Excel reports with logging, so a routine report runs in one step.

    Explain

    Clear findings for business readers

    I turn results into short summaries, READMEs and decks that a manager can act on.
