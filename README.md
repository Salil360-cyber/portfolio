# portfolio

Personal portfolio of **Salil Gokhale**, Data Analyst: SQL, Excel, Power BI, Tableau, Python and AI.

**Live site:** https://salil360-cyber.github.io/portfolio/

Built with plain HTML, CSS and JavaScript (Three.js for the petri-dish hero and the globe). No build step. Hosted on GitHub Pages. Visitor analytics by GoatCounter (privacy-friendly, no cookies).

- `index.html` contains the whole site. Project data is in the `PROJECTS` list inside it.
- `assets/` holds the photo, favicon, share image, resume and project screenshots.
